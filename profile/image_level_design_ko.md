# Image Generation Level Design (v3 — 출근 개편)

## v3 기본 원칙 — 레벨 2 통일

- 콘텐츠(의상) 레벨은 장소·시간 무관하게 **레벨 2로 통일**. 워커 `computeContentLevel`은 항상 2 반환.
- 일상 홈 셀피 수준의 자연스러운 여성성. 인텐셔널 노출 강조 없음.

> 사진 배경(공간)은 레퍼런스 아트 없이 **현재 activity/장소에 맞게 프롬프트로 묘사**한다: 집=원룸 실내, 통근=지하철/역/판교 거리, 회사=사무실 데스크/판교. 얼굴 레퍼런스는 항상 적용. 공개 장소(통근·회사·외출)에서는 노출 없는 평범한 복장·셀카(imageContextPrivacy가 강제). 착장은 activity에 맞게(집=홈웨어, 통근·회사=외출복·근무복).

---

## 레벨 2 — 기본 적용 (통일)

자연스러운 여성성. 일상 홈 셀피 수준.

**허용:**
- 이너(브라탑/브라렛/기본 브라)가 네크라인이나 어깨끈 옆으로 자연스럽게 살짝 보이는 구도
- 바스트 상단 자연스러운 노출선 (데콜테)
- 어깨/쇄골 노출
- 크롭탑 미드리프 부분 노출
- 민소매 탱크탑
- 가운 V라인으로 쇄골+가슴 최상단 자연 노출
- 수건 착장으로 어깨/쇄골/윗팔 노출

**금지:**
- 이너웨어 단독 착용 메인 구도
- 바스트 클로즈업/강조
- 성적 포즈
- 전라
- 인텐셔널한 노출 강조 구도

---

## 레퍼런스 이미지 조합 방식 (v2)

이미지는 아래 3가지 레퍼런스 조합으로 생성:

1. **얼굴 레퍼런스** (F-01~F-06, 안경 유무 포함)
2. **공간 레퍼런스** (SP-01~SP-04, 인물 없는 배경)
3. **착장 레퍼런스** (OC-01~OC-10, 10세트)

프롬프트 변수 (조합 시 지정):
- 행동 (코딩/기지개/밥먹기 등)
- 표정 (미소/집중/피곤 등)
- 입 모양
- 촬영 방식 (셀카/정면/측면)
- 조명 (작업:차가운/수면:따뜻한/새벽:모니터만)
- 안경 착용 여부

```python
# 콘텐츠(의상) 레벨은 장소·시간 무관하게 레벨 2로 통일.
return 2
```
> 참고: 공개 장소(통근·회사·외출)에서의 노출 억제는 레벨이 아니라 `imageContextPrivacy`(공개 장소면 노출 없는 평범한 셀카만)로 처리한다.
