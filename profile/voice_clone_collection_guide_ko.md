# Voice Clone Collection Guide

## 목표

- ElevenLabs에 넣을 웅삐용 한국어 음성 데이터를 일관된 품질로 모은다.

## 권장 분량

- 총합: `20분 ~ 40분`
- 파일 길이: `30초 ~ 90초`
- 파일 수: `20개 이상`

## 필수 조건

- 한 파일에 한 사람 목소리만
- 배경음악 없음
- 다른 사람 목소리 없음
- 에코 적음
- 너무 작은 소리 피하기
- 가능한 같은 방, 같은 마이크

## 권장 내용

- 일상 대화체
- 차분한 설명
- 애정 표현이 섞인 자연스러운 말
- 자주 쓸 단어 포함
  - `오빠`
  - `안녕`
  - `잘 챙겨`
  - `오늘`
  - `보고 싶어`

## 피할 것

- 울음/웃음만 많은 파일
- 속삭임 위주
- 전화통화 녹음
- 반주 깔린 영상 음원 추출본
- 리버브/보정 심한 파일
