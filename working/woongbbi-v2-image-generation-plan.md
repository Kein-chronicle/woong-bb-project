# 웅삐 v2 이미지 생성 계획

> 기존 방식: 상황마다 프롬프트 전체 작성 → 매번 다른 결과
> 신규 방식: 레퍼런스 이미지 조합 → 고정 요소 + 프롬프트는 행동/표정/촬영만

---

## 생성 방식 구조

```
[공간 레퍼런스] + [착장 레퍼런스] + [얼굴 레퍼런스]
      ↓
   조합 입력
      ↓
[행동] + [표정] + [입 모양] + [촬영 방식] + [조명]
      ↓
   최종 이미지
```

## 조합 시 프롬프트 구성 요소

착장+공간 레퍼런스 이미지를 넣고, 아래 요소만 텍스트로 지정.

### 행동 (Action)
```
코딩 중 / 기지개 켜기 / 턱 괴기 / 밥 먹는 중 /
커피 들기 / 누워있기 / 폰 보기 / 요리 중 / 엎드려 있음
```

### 표정 (Expression)
```
중립 / 미소 / 집중 / 피곤함 / 귀여운 무표정 /
살짝 웃음 / 졸린 표정 / 뭔가 생각 중
```

### 입 모양 (Mouth)
```
다물기 / 살짝 열림 / 미소로 살짝 열림 / 뭔가 먹는 중
```

### 촬영 방식 (Shot)
```
셀카 (자가 촬영 느낌) / 정면 / 반 측면 / 측면 /
위에서 내려다보기 / 약간 아래에서 올려다보기
```

### 안경 (Variable)
```
안경 없음 / 안경 착용
```
> 착장/상황에 따라 선택. 기본값 없음. 장면마다 지정.
> 작업 집중 중: 안경 착용 빈도 높음
> 취침/욕실 착장: 안경 없음

### 화질 방향
```
photorealistic, real photograph quality, natural skin texture,
soft natural lighting, candid photo feel
```

### 조명 (공간별 고정값)
```
작업 중: 차가운 백색 + 모니터 빛
수면/휴식: 따뜻한 황색
새벽: 모니터만 어두운 방
낮: 창문 자연광
```

## 레퍼런스 생성 순서

```
1단계: 얼굴 레퍼런스 (F-01~06, 안경 포함) — 가장 먼저
2단계: 공간 레퍼런스 (SP-01~04) — 인물 없이
3단계: 착장 레퍼런스 (OC-01~10) — 얼굴 레퍼런스 기반
4단계: 조합 테스트 — 1~2개 장면으로 검증
5단계: 전체 15장면 생성
```

## 고려해야 할 추가 항목

| 항목 | 내용 |
|------|------|
| 헤어 변주 | 착장별 헤어가 specs에 고정돼있음. 일치 확인 필요. |
| 손/제스처 | 셀카 들고 찍는 손 / 키보드 위 손 / 음식 드는 손 등 프롬프트 추가 |
| 피부 수분감 | O-09/10 (욕실 착장)은 피부 촉촉한 묘사 명시 필요 |
| 안경 여부 | 캐릭터에 안경 설정 있는지 없는지 결정 필요 |
| 배경 흐림(DOF) | 인물 포커스 + 배경 살짝 아웃포커스가 자연스러움 |
| 화질 기준 | 픽셀아트 아님. 실사/일러스트 중 결정 필요 (기존 eunbi는 실사형) |
