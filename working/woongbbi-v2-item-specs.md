# 웅삐 v2 아이템 상세 스펙

> 이미지 생성 시 모든 장면에서 일관되게 적용.
> 명칭만 아닌 색·질감·형태·두께까지 고정.

---

## 1. 컴퓨터 데스크 구역

### 모니터
| 항목 | 값 |
|------|-----|
| 개수 | 1대 |
| 크기 | 27인치급 (공간 대비 큼) |
| 형태 | 얇은 베젤, 직사각형 평면 (곡면 아님) |
| 색상 | 무광 검정 (matte black) 프레임 |
| 화면 | 코드 에디터 띄워진 상태 (어두운 배경에 컬러 텍스트) |
| 스탠드 | 가는 실버 메탈 스탠드 |
| 받침 | 작은 검정 플라스틱 베이스 |

### 키보드
| 항목 | 값 |
|------|-----|
| 종류 | 풀배열 기계식 키보드 |
| 색상 | 흰색 or 회색 키캡, 검정 바디 |
| 높이 | 납작한 저프로파일 |
| 백라이트 | 흰색 or 냉색 블루 (RGB 무지개 아님) |
| 재질 | 플라스틱 + 알루미늄 상단 패널 |

### 마우스
| 항목 | 값 |
|------|-----|
| 형태 | 무선, 심플한 타원형 |
| 색상 | 검정 or 다크 그레이 |
| 패드 | 크고 얇은 검정 마우스패드 (데스크 거의 덮음) |

### 데스크 (책상)
| 항목 | 값 |
|------|-----|
| 크기 | 좁고 긴 형태 (1인 전용) |
| 재질 | 연한 베이지/오크 우드 상판 |
| 다리 | 흰색 or 검정 메탈 프레임 |
| 높이 | 표준 (앉아서 딱 맞는) |
| 마감 | 무광, 깔끔함 — 흠집/낙서 없음 |
| 위에 올라간 것 | 모니터 + 키보드 + 마우스패드 + 머그컵 1개만 |

### 의자
| 항목 | 값 |
|------|-----|
| 종류 | 미니 에르고노믹 체어 (팔걸이 있음) |
| 색상 | 검정 메시 등받이, 검정 시트 |
| 다리 | 검정 바퀴달린 금속 다리 |
| 쿠션 | 얇고 단단한 시트 쿠션 |
| 높이 | 낮춰서 앉은 상태 기준 |

### 머그컵 (데스크 소품)
| 항목 | 값 |
|------|-----|
| 형태 | 두꺼운 세라믹, 심플 원통형 |
| 색상 | 흰색 or 짙은 네이비 |
| 데칼 | 없음 (민무늬) |
| 내용물 | 검은 커피 or 연한 갈색 (아메리카노/라떼) |

## 2. 침대 구역

### 침대 프레임
| 항목 | 값 |
|------|-----|
| 크기 | 1인용 싱글 |
| 프레임 | 낮고 납작한 플랫폼 베드 (헤드보드 있음) |
| 헤드보드 | 낮고 평평한 직사각형, 두께 10cm 내외 |
| 재질 | 연한 베이지/오크 우드 or 패브릭 헤드보드 |
| 색상 | 내추럴 베이지 or 연회색 |
| 다리 | 없음 or 아주 짧은 나무 다리 (로우 플랫폼) |

### 매트리스
| 항목 | 값 |
|------|-----|
| 두께 | 중간 (20cm 내외) |
| 색상 | 흰색 커버 |

### 이불 (메인)
| 항목 | 값 |
|------|-----|
| 종류 | 가벼운 솜이불 or 이중거즈 이불 |
| 색상 | **연한 민트 or 흰색** (메인 컬러) |
| 질감 | 부드럽고 가벼워 보임, 주름 자연스럽게 |
| 두께 | 얇고 가벼운 사계절용 |
| 상태 | 잘 때: 몸 위에 덮임 / 낮: 접혀서 침대 발치에 |

### 베개
| 항목 | 값 |
|------|-----|
| 개수 | 2개 |
| 크기 | 표준 사이즈 (50×70cm급) |
| 커버 색상 | 흰색 or 연회색 |
| 질감 | 약간 구겨진 코튼 면 소재 |
| 높이 | 적당히 봉긋한 (너무 납작하지 않게) |

### 침대 시트
| 항목 | 값 |
|------|-----|
| 색상 | 흰색 or 연한 회색 |
| 질감 | 면 소재, 약간 구겨진 자연스러운 상태 |
| 피팅 | 매트리스에 딱 맞게 깔린 상태 |

### 침대 옆 무드등
| 항목 | 값 |
|------|-----|
| 형태 | 작은 원통형 or 둥근 구형 |
| 색상 | 흰색 or 아이보리 |
| 빛 색 | 따뜻한 황색 (warm white 2700K) |
| 위치 | 헤드보드 옆 바닥 or 작은 선반 위 |

---

## 3. 식탁 / 주방 구역

### 식탁
| 항목 | 값 |
|------|-----|
| 크기 | 1인용 원형 or 작은 사각형 (지름 60cm급) |
| 재질 | 연한 우드 상판 |
| 다리 | 얇은 검정 메탈 다리 |
| 의자 | 없음 or 접이식 스툴 1개 |

### 주방
| 항목 | 값 |
|------|-----|
| 레인지 | 작은 2구 가스레인지 or 인덕션 |
| 냉장고 | 소형 (키 80~90cm급), 흰색 or 실버 |
| 씽크대 | 작은 싱글 씽크, 흰색 |
| 수납 | 상부 작은 선반 1~2개 |
| 전체 색상 | 흰색 계열 |

---

## 4. 창문

| 항목 | 값 |
|------|-----|
| 위치 | 데스크 위쪽 벽 (앉으면 눈높이 위) |
| 크기 | 가로 60cm × 세로 40cm 내외 |
| 형태 | 직사각형 가로형 |
| 프레임 | 흰색 or 알루미늄 실버 |
| 커튼 | 얇은 반투명 흰색 커튼 (블라인드 아님) |
| 밖 | 하늘만 — 낮:파란 하늘 or 흐린 하늘, 밤:어두움, 새벽:보랏빛 |

---

## 5. 벽 & 바닥

| 항목 | 값 |
|------|-----|
| 벽 색상 | 따뜻한 흰색 (pure white 아닌 off-white) |
| 바닥 | 연한 우드 패턴 장판 or 원목 |
| 천장 | 흰색, 낮은 천장 |
| 벽 장식 | 없음 (최소화) |
