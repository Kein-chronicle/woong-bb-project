# 웅삐 v2 착장 스펙 (10세트)

> 이미지 생성 레퍼런스용. 각 세트별 독립 이미지 생성 권장.
> 콘텐츠 기준: **레벨 2** — 이너웨어가 네크라인/틈으로 자연스럽게 살짝 보이는 수준. 강조·클로즈업 금지. 일상 셀피 수준.
> 외출 없음 → 전부 홈웨어/실내복.

---

## 레벨 2 적용 기준 (공통)

- 브라탑/브라렛/기본 브라가 네크라인 틈, 어깨끈 옆으로 자연스럽게 살짝 노출 → **허용**
- 배꼽 or 복부 일부 노출 (크롭 착장 한정) → **허용**
- 허벅지 일부 (짧은 반바지) → **허용**
- 강조 앵글, 클로즈업, 특정 부위 포커스 → **금지**
- 의도적 과노출 or 자세 과장 → **금지**

## 평상시 복장 (6세트)

### O-01 기본 작업복

| 항목 | 상세 |
|------|------|
| 상의 | 오버핏 흰색 반팔 티셔츠. 넓은 라운드넥. 밑단 허벅지 중간. 부드러운 면 소재. |
| 이너 노출 | 넓은 라운드넥 사이로 흰 브라렛 or 브라탑 어깨끈이 어깨 쪽으로 살짝 보임. 의도 없이 자연스럽게. |
| 하의 | 짧은 검정 반바지. 고무줄 허리. 매끈한 면 소재. |
| 양말 | 없음 (맨발) |
| 헤어 | 높은 포니테일. 앞머리 자연스럽게 내려옴. 잔머리 약간. |
| 헤어 소품 | 검정 고무줄 포니테일. 손목에 베이지 스크런치 1개. |
| 귀걸이 | 없음 |
| 레벨2 포인트 | 넓은 넥라인 옆 브라렛 끈 자연 노출 |

## 욕실 전후 (2세트)

### O-09 욕실 가운

| 항목 | 상세 |
|------|------|
| 착장 | 흰색 무릎 위 3~4cm 길이 테리 코튼 욕실 가운. 허리 벨트 느슨하게 묶임. 소매 7부. |
| 노출 범위 | 벨트 위 가슴 방향 V 라인으로 목~가슴 상단 피부/쇄골/가슴 최상단 노출. 과하지 않게. 허리 벨트 아래는 닫혀 있음. |
| 헤어 | 수건 터번으로 머리 감싼 상태 or 젖은 머리 풀어헤침. |
| 헤어 소품 | 흰 수건 터번 (옵션) |
| 발 | 맨발 or 흰 슬리퍼 |
| 기타 | 볼 살짝 붉음 (샤워 후) |
| 레벨2 포인트 | 가운 V 라인으로 쇄골+가슴 최상단 자연 노출. 강조 금지. |

### O-10 수건 착장

| 항목 | 상세 |
|------|------|
| 착장 | 흰색 대형 배스타월. 겨드랑이 아래에서 허벅지 중간 높이까지 두름. 어깨+쇄골+윗팔 노출. |
| 노출 범위 | 어깨, 쇄골, 목, 윗팔 노출. 타월은 가슴 위에서 시작해서 허벅지 중간까지 덮음. 강조 구도 없이 자연스러운 자세. |
| 헤어 | 젖은 머리. 자연스럽게 내려옴. 약간 어두운 색감. |
| 헤어 소품 | 없음 |
| 발 | 맨발 |
| 기타 | 피부 수분기, 볼 붉음 |
| 레벨2 포인트 | 어깨/쇄골 노출. 타월 상단 위치는 가슴 윗선 이상 유지. 클로즈업 금지. |
