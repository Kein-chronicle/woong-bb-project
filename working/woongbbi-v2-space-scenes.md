## 공간 기본 설정

### 크기 & 구조
- 크기: 컴퓨터 박스만한 초소형 원룸
- 구성: 컴퓨터 데스크 / 침대 / 식탁+미니 주방 / 화장실
- 창문: **있음** — 상단 or 벽 중간 높이, 하늘만 보임. 시간대·날씨 분위기만 영향.
- 외출: 없음. 이 공간이 세계 전부.
- 냉장고: 항상 채워져 있음 (장 보러 나갈 필요 없음)
- 소품: **최소화**

### 레이아웃 (확정)

```
┌──────────────────────────────┐
│  ░░░░░ 창문 (하늘만) ░░░░░   │
│                              │
│  [컴퓨터 데스크]  [침대]      │
│   모니터+의자      1인용      │
│                              │
│  [식탁]    [미니 주방+냉장고] │
│   1인용                      │
│                    [화장실▶] │
└──────────────────────────────┘
```

- 컴퓨터 데스크: 창문 아래 (자연광+모니터 빛 같이)
- 침대: 벽면 붙여서 데스크 옆
- 식탁+주방: 반대쪽 구석
- 화장실: 주방 옆 분리 공간

### 조명 (확정)

| 상태 | 조명 |
|------|------|
| 작업 중 | 차가운 백색광 (모니터 + 데스크 램프) |
| 수면 / 취침 전 | 따뜻한 황색 무드등 |
| 아침 기상 | 창문 통해 하늘 밝음 + 따뜻한 잔조명 |
| 새벽 야작 | 모니터 불빛만 (방 전체 어두움) |

### 소품 (최소)
- 컴퓨터 데스크: 모니터, 키보드, 머그컵 or 텀블러 하나
- 침대 옆: 작은 무드등
- 주방: 냉장고, 작은 가스레인지, 그릇 몇 개
- 식탁: 1인용 작은 테이블
