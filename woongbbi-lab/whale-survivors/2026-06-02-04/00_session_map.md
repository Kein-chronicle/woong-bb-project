# 세션 흐름 지도

세션 ID: `2026-06-02-04`

## 어디서 시작했나

- 나는 이번 세션의 필수 과제 중에서 `Act 1/2/3 허가서 전체 표`를 메인 과제로 잡았다.
- 이유는 이전 세션들에서 `허가서`와 `연구`의 방향은 이미 합의됐지만, 실제 오픈 곡선을 운영 가능한 표로 내린 적은 없었기 때문이다.

## 시작 전에 둔 가정

- 나는 이번에도 `승인 무기 20종`, `태그 1~4단계`, `항해 노드`만으로 닫아야 한다고 가정했다.
- 허가서는 `즉시 전투 스펙 상승`이 아니라 `다음 런 후보군과 목표 개방`만 담당해야 한다고 가정했다.
- 이번 세션은 코드 반영이 아니라, 저장 가능한 설계 문서와 실험용 데이터 틀까지 만드는 데서 멈춘다.

## 실제 탐구 경로

1. 이전 세션 결과를 다시 읽고, 이미 합의된 결론과 아직 빈 칸을 분리했다.
2. 처음엔 허가서 표만 쓰려 했지만, 표만 있으면 플레이어 표면 경험이 약하다고 판단했다.
3. 그래서 옆길로 잠깐 빠져 `플레이어 UI 문구`와 `항해 노드 예시`를 같이 붙이기로 했다.
4. 다시 메인 과제로 돌아와 `Act별 역할 -> 허가서 풀 -> 연결 문구 -> 노드 예시` 순서로 묶었다.

## 어디서 돌아왔나

- 한때 `맹독`, `정령`, `기동`, `소환`까지 태그 전부를 같은 세션에 넓히려 했는데, 그러면 또 범위가 퍼진다고 봤다.
- 그래서 이번 세션에서는 확장 대신 `4태그 파일럿을 더 플레이어 친화적으로 보이게 만드는 일`만 남겼다.

## 이번 세션에서 실제로 진전시킨 것

- `Act 1/2/3 허가서 전체 표`를 작성했다.
- 허가서가 어떤 연구 과제 문구와 연결되는지 플레이어 문장 수준으로 적었다.
- 항해 노드 허가가 월드맵에서 어떻게 보일지 예시를 따로 뽑았다.
