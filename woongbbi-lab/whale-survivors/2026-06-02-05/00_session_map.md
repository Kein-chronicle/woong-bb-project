- 나는 이번에도 실제 게임 코드는 건드리지 않고 `woongbbi-lab/` 안 문서와 데이터 초안만 만든다.

## 실제 탐구 경로

1. 직전 세션의 `03_tag_ui_copy.md`를 다시 읽고 문구 리듬과 판정 방식을 맞췄다.
2. 곧바로 4태그 문구를 늘리기보다, 이전 점수 메모에서 `맹독은 유지/생존`, `정령은 자동 추적`, `기동은 무피격 운용`, `소환은 필드 유지` 같은 감각을 먼저 다시 확인했다.
3. 그다음 `맹독·정령·기동·소환` 각각에 대해 1단계와 2단계 연구 문구, 진행 문구, 실패 피드백을 적었다.
4. 중간에 `정령-맹독 교차 연구`도 같이 닫을지 고민했는데, Act 3 허가서의 예고 슬롯이 이미 있었으니 이번에 같이 붙이는 편이 맞다고 판단했다.
5. 마지막으로 문장을 그대로 재사용할 수 있게 JSON 초안을 따로 만들었다.
