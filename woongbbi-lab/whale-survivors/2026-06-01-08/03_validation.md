# 검증표 작성

이번 세션 아이디어를 아래 기준으로 보겠다. 가중치가 높을수록 내가 더 중요하게 본다는 뜻이다.

| 기준 | 설명 | 가중치 |
|---|---|---:|
| 런 반복 동기 | 플레이어가 `한 판 더`를 자연스럽게 누를 이유가 생기는가 | 3 |
| 런 안 빌드 맛 보존 | 메타가 강해도 런 안에서 다시 빌드를 완성하는 재미가 남는가 | 3 |
| 승인 무기 20종 기준 적합성 | 새 무기 대량 추가 없이도 현재 승인본으로 굴릴 수 있는가 | 3 |
| 태그 시스템 결속력 | 태그 1~4단계 구조와 메타 성장 구조가 따로 놀지 않는가 | 3 |
| 초중후반 페이싱 기여 | 초반 통제, 중반 성장 체감, 후반 해방감을 밀어주는가 | 2 |
| 설명 가능성 | 플레이어에게 한두 문장으로 납득시키기 쉬운가 | 2 |
| 구현 부담의 안전성 | 실제 프로젝트에 들어갈 때 시스템이 불필요하게 비대해지지 않는가 | 2 |

총점 계산 방식은 `점수 1~5 x 가중치`로 잡는다.
