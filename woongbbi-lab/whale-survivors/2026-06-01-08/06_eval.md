# 최종 평가

## 이번 세션에서 배운 것

- 나는 이번에, 웨일서바이버 메타 성장이 `영구 능력치 구매`보다 `다음 런의 전략 공간을 여는 선택` 쪽으로 가야 훨씬 잘 맞는다고 더 확신하게 됐다.
- 특히 태그 시스템은 전투 안에서만 끝낼 게 아니라, 메타에서도 `연구`, `해금`, `다음 목표`의 언어로 재사용할 수 있다.
- 그리고 외부 사례를 보고 나니, 좋은 해금은 새 콘텐츠를 많이 붓는 것보다 `기존 콘텐츠의 관계를 다시 보이게 하는 것`이라는 점이 더 선명해졌다.

## 잘 된 것

- 이전 세션의 추상 방향을 이번엔 `엑트 보상 드래프트`와 `태그 연구 과제`라는 시스템 언어로 좁혔다.
- 리서치 결과가 실제 설계 판단으로 이어졌다. 특히 `수평 해금`, `과제형 반복 동기`, `interaction gating`이 직접 영향을 줬다.
- 승인 무기 20종 기준으로도 충분히 굴릴 수 있는 구조만 남겨서, 아이디어가 과장되지 않았다.

## 부족한 것

- 태그별 연구 과제를 실제 표로 풀지 못했다. 지금은 구조만 있고, 각 태그의 과제 맛 차이는 아직 없다.
- 항해 노드 해금과 태그 연구가 서로 어떤 순서로 얽히는지 세부 루프를 더 다듬어야 한다.
- 보상 UI 문구, 연구 진행 표시, 실패했을 때의 피드백 문구 같은 플레이어 표면 경험은 아직 비어 있다.

## 다음 세션에 이어받을 씨앗

1. `Act 1/2/3`별 보상 풀을 실제 표로 작성해서, 어떤 문이 언제 열리는지 오픈 곡선을 보겠다.
2. `저주`, `공명`, `냉기`, `압력`부터 4개 태그만 먼저 골라 연구 과제 초안을 만들겠다.
3. 항해 노드 중 어떤 것들이 `연구 보상형`, `빌드 보정형`, `리스크-리턴형`인지 분류표를 만들겠다.

## 한 줄 요약

오빠한테 보고하면, `웨일서바이버 메타 성장은 숫자 업보다 엑트 보상으로 전략 문을 열고 태그 연구로 깊이를 여는 쪽이 더 잘 산다`로 정리하면 된다.
