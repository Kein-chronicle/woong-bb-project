# 전투력 1차 계산식

이번 문서는 `엑트1 기준 전투력 점수 v0.1` 초안이다.

전제:

- 기준 구간: `엑트1`
- 슬롯 수: `3`
- 무기 레벨 상한: `3`
- 태그 게이지 기대 상한: `9`
- 목표: `표시 화력`이 아니라 `실전 체감 전투력`을 한 줄 점수로 근사

---

## 1. 최상위 식

`최종전투력 = 무기총점 + 태그점수 + 생존점수 + 운영점수`

여기서 무기총점은 다시 아래처럼 계산한다.

`무기총점 = Σ 무기점수(i, L_i) + 조합보너스 - 조합패널티`

- `i`: 장착한 3개 무기
- `L_i`: 각 무기의 현재 레벨

---

## 2. 무기 점수

무기 하나의 점수는 고정값이 아니라 `기본점수 x 레벨 성장` 구조로 둔다.

`무기점수(i, L) = [기본무기점수(i)] x [레벨계수(i, L)]`

### 2-1. 기본무기점수

`기본무기점수(i) = 단일화력(i) + 광역화력(i) + 유틸가치(i) + 태그기여(i)`

권장 세부식:

`기본무기점수(i) = 0.45x단일DPS + 0.30x광역DPS + 0.15x유틸점수 + 0.10x태그기여점수`

메모:

- `단일DPS`: 보스/엘리트 상대로 안정적으로 들어가는 화력
- `광역DPS`: 잡몹 정리, 범위 커버, 관통/폭발 포함 화력
- `유틸점수`: 넉백, 둔화, 자동추적, 사거리 안정성, 회전 편의
- `태그기여점수`: 해당 무기가 태그 단계 활성에 기여하는 정도

### 2-2. 레벨계수

무기 레벨 성장은 공용 상수보다 무기별 테이블을 권장한다.

예시 테이블:

- `L1 = 1.00`
- `L2 = 1.30`
- `L3 = 1.70`

단, 실제 적용은 아래처럼 분리해도 된다.

`레벨계수(i, L) = 공격성장(i, L) + 유틸성장(i, L) + 태그성장(i, L)`

즉 어떤 무기는 레벨업이 단일딜을 크게 올리고,
어떤 무기는 범위나 태그 기여를 더 많이 올리는 차이를 남긴다.

---

## 3. 조합 보정

무기 3개는 단순 합산으로 끝내지 않는다.

`조합보너스 = 역할시너지 + 태그연결보너스`

`조합패널티 = 운용충돌패널티 + 과잉중복패널티`

### 보너스 예시

- 메인딜 + 잡몹처리 + 보조유틸 역할이 고르게 맞물림
- 3개 무기가 같은 핵심 태그를 2단계 이상까지 자연스럽게 올려줌
- 사거리/공속/발동 리듬이 서로 보완됨

### 패널티 예시

- 셋 다 단일딜만 강하고 잡몹 정리가 없음
- 셋 다 쿨이 길어 공백 시간이 큼
- 태그는 많이 흩어지는데 실제 활성 단계는 낮음

---

## 4. 태그 점수

무기 점수와 분리해서 계산한다.

`태그점수 = Σ [태그기본값 x 단계보정 x 시너지보정]`

단계보정 예시:

- `1단계 = 1.00`
- `2단계 = 1.35`
- `3단계 = 1.80`

메모:

- 딜 태그, 생존 태그, 운영 태그는 기본값이 다를 수 있음
- 같은 2단계라도 실제 빌드 폭발력이 큰 태그는 시너지보정을 더 높게 둘 수 있음

---

## 5. 생존/운영 점수

### 생존점수

`생존점수 = 유효체력 + 피격완화 + 회복/실드 + 거리안전성`

메모:

- 탱킹 절대치보단 `딜을 유지할 수 있는 안정성` 기준으로 둔다

### 운영점수

`운영점수 = 회전율 + 자원수급 + 조건달성난이도 역보정 + 조작안정성`

메모:

- 이 점수가 없으면 종이상 강한데 실제론 손이 꼬이는 빌드가 과대평가된다

---

## 6. 시간축 기대 전투력

정적 전투력과 별도로 `분 단위 기대 전투력`을 둔다.

`기대전투력(t) = 시작전투력 + 드로우기대증가(t) + 레벨기대증가(t) + 태그기대증가(t)`

엑트1 첫 런 기준 초기 구간 초안:

- `T=0분`: 시작 장비 전투력
- `T=1분`: 기대 드로우 3~4회 기준
- `T=2분`: 기대 드로우 6~8회 기준
- `T=3분`: 기대 드로우 9~12회 기준

각 구간은 `저점 / 평균 / 고점` 세 줄로 관리한다.

---

## 7. 기준점 고정

비교를 위해 기준 조합 하나를 `100점`으로 고정한다.

권장 규칙:

- `엑트1 클리어 표준 조합 = 전투력 100`
- `90 전후 = 약한 편`
- `110~120 = 강한 편`
- `130+ = 과성장 가능성 체크`

---

## 8. 지금 바로 검증할 것

1. 표준 조합 1개를 넣었을 때 `100` 근처가 나오는지
2. 저점 조합 2개가 실제 체감처럼 `100 아래`로 떨어지는지
3. 고점 조합 2개가 실제 체감처럼 `100 위`로 올라가는지
4. 2분 시점 기대 드로우 `6~8회` 기준 전투력이 액트1 난이도 곡선과 맞는지

## 9. 1차 샘플 검증

레벨 3 기준 `baseDps`만 먼저 꽂아본 빠른 검토.

### 무기별 레벨3 baseDps 상위

| 무기 | 레벨3 baseDps |
|---|---:|
| bowheadIcebreaker | 480.00 |
| orcaPod | 114.71 |
| narwhalLance | 86.15 |
| polarShock | 82.31 |
| resonanceCursbeam | 79.29 |
| contagion | 75.33 |
| pressureInscript | 74.38 |

### 샘플 조합 A — 공명/저주 표준형

- `blueSong + curseEcho + resonanceCursbeam`
- 무기 baseDps 합: `20.31 + 13.00 + 79.29 = 112.60`
- 태그 상태: `공명 3 / 저주 3`

읽힘:

- 무기 합은 중간 정도
- 대신 태그 3단계가 둘 다 빠르게 켜질 수 있어서, `태그점수` 비중이 꽤 커야 함
- 즉 표준형 기준점 100에 가까운 샘플 후보로 괜찮아 보임

### 샘플 조합 B — 압력/관통 고점형

- `narwhalLance + polarShock + pressureInscript`
- 무기 baseDps 합: `86.15 + 82.31 + 74.38 = 242.84`
- 태그 상태: `압력 3 / 냉기 1 / 저주 1`

읽힘:

- 무기 화력 총합은 높은데 태그 완성은 한 축에 몰림
- 보스/직선 관통 고점 조합으로 보기 좋음
- 표준형보다 높은 점수가 나와야 정상

### 샘플 조합 C — 장판/운영 저점형

- `frostResonanceField + venomChargeField + toxinSwimmer`
- 무기 baseDps 합: `2.60 + 3.20 + 29.50 = 35.30`
- 태그 상태: `맹독 2 / 냉기 1 / 공명 1 / 압력 1 / 정령 1`

읽힘:

- 현재 식 기준으로는 확실히 저점
- 대신 둔화, 장판 유지, 운영 안정성 쪽 값이 무기 dps에 거의 반영되지 않음
- 즉 `유틸점수/운영점수`가 충분히 안 크면 실제보다 너무 약하게 평가될 위험이 있음

### 샘플 조합 D — 현재 식의 과대평가 경고

- `bowheadIcebreaker + polarGuard + frostEcho`
- 무기 baseDps 합: `480.00 + 53.89 + 12.78 = 546.67`

읽힘:

- 현 시점 수치만 보면 다른 조합을 압도적으로 밀어버림
- 이건 `bowheadIcebreaker`의 접촉 지속형 특성이 `baseDps`에 그대로 과대 반영됐을 가능성이 큼
- 즉 지금 식에는 `실전 명중률/접촉 유지율/유효 가동시간` 보정이 추가로 필요함

## 10. 1차 결론

이번 빠른 검토로 바로 보인 것:

1. `무기 dps 순서` 자체는 대체로 감각적인 고점/저점 구분에 도움 됨
2. 하지만 `지속 접촉형/장판형/유틸형`은 baseDps만으로 보면 왜곡이 큼
3. 따라서 v0.2에서는 아래 보정이 꼭 들어가야 함

- `실전 가동률 보정`
- `유틸 기여 보정`
- `태그 조기완성 보정`

한 줄로 정리하면,
`현재 v0.1은 투사체/직선딜 비교엔 쓸 만하지만, 장판형/접촉형은 그대로 넣으면 왜곡된다.`

## 11. v0.2 업데이트안 — 처치력/생존력 이원화

v0.1의 핵심 문제는 `얼마나 빨리 죽이느냐`가 `얼마나 안전하게 버티며 공간을 만드느냐`를 덮어버린다는 점이다.

웨일서바이버는 단일 보스 딜보다 `사방에서 몰려오는 적을 비우는 능력`이 훨씬 중요하므로,
v0.2부터는 최종 점수를 아래처럼 두 축으로 나눈다.

### 11-1. 최상위 식

`최종전투력(v0.2) = 0.40x처치력 + 0.40x생존력 + 0.10x태그시너지 + 0.10x운영안정성`

메모:

- `처치력`: 보스/엘리트/고체력 적을 빠르게 줄이는 능력
- `생존력`: 포위 상황에서 숨 쉴 공간을 만들고 유지하는 능력
- `태그시너지`: 태그 단계가 실제 전투 흐름을 얼마나 폭발시키는지
- `운영안정성`: 손이 꼬이지 않고 지속적으로 굴러가는지

즉 v0.2는 `딜이 강하면 무조건 센 빌드`라는 가정을 버리고,
`잘 죽이면서도 안 죽는 빌드`를 높은 점수로 밀어준다.

### 11-2. 처치력

`처치력 = 단일처치력 + 광역처치력`

권장 세부식:

`처치력 = 0.55x단일처치력 + 0.45x광역처치력`

#### 단일처치력

`단일처치력 = 단일보정DPS x 집중타격보정`

반영 요소:

- 엘리트/보스 상대로 안정적으로 맞는지
- 사거리 때문에 실제 딜 누수가 큰지
- 쿨이 길어 빈딜 구간이 큰지

#### 광역처치력

`광역처치력 = 광역보정DPS x 범위커버보정 x 군중분산보정`

반영 요소:

- 범위가 넓은지
- 관통/폭발/연쇄로 여러 줄을 같이 지우는지
- 적이 사방에서 들어올 때도 커버가 유지되는지

### 11-3. 생존력

v0.2의 핵심 추가 축.

`생존력 = 공간확보력 + 압박완화력 + 유지안정성`

권장 세부식:

`생존력 = 0.45x공간확보력 + 0.35x압박완화력 + 0.20x유지안정성`

#### 공간확보력

플레이어 주변에 빈 공간을 만드는 능력.

반영 요소:

- 근접 적을 즉시 밀어내거나 정리하는지
- 플레이어 주변 360도 커버가 되는지
- 자동추적, 원형 궤도, 장판 유지처럼 빈 공간을 오래 유지하는지

#### 압박완화력

적의 진입 속도와 압력을 깎는 능력.

반영 요소:

- 둔화, 빙결, 넉백, 경직
- 적 무리의 속도를 늦추는 태그/효과
- 위험 구간에서 한 번 버티게 해주는 임시 완충 효과

#### 유지안정성

강한 순간화력이 아니라 `계속 안전한지`를 보는 점수.

반영 요소:

- 공백 시간 없이 공격이 순환되는지
- 적이 몰렸을 때도 포지션 붕괴 없이 유지되는지
- 접촉형 무기가 실제로 붙어 있어야만 딜이 나는 구조인지

### 11-4. 태그시너지

v0.1의 태그점수는 유지하되, v0.2에선 `생존 태그`와 `처치 태그`를 분리해서 해석한다.

`태그시너지 = 처치태그점수 + 생존태그점수 + 운영태그점수`

메모:

- `압력/저주/공명`처럼 화력 폭발이 큰 태그는 처치 쪽 가중
- `냉기/맹독 유지/회복/실드` 같은 축은 생존 쪽 가중
- 같은 3단계라도 어느 축을 밀어주는지 다르게 본다

### 11-5. 운영안정성

기존 운영점수보다 역할을 더 좁힌다.

`운영안정성 = 회전안정성 + 조건달성용이성 + 조작부담역보정`

메모:

- 이 축은 빌드가 강한데도 손이 너무 바쁜 경우를 깎는다
- 다만 v0.2에서는 운영이 생존을 대신하지 않는다
- 생존은 반드시 `공간과 압박` 기준으로 따로 계산한다

### 11-6. 실전 가동률 보정

v0.1에서 가장 크게 부족했던 부분.

`실전가동률보정 = 명중유지율 x 접촉유지율 x 포위상황유효율`

무기 점수에 직접 곱하거나, 처치력/생존력 산식 내부 보정으로 사용한다.

#### 필요한 이유

- 직선딜 투사체는 종이상 dps가 높아도 사방 포위에선 누수가 큼
- 접촉형 무기는 이론 dps가 높아도 실제 유지가 어려울 수 있음
- 장판형은 baseDps는 낮아도 포위 상황 유효율이 높을 수 있음

즉 `보이는 dps`가 아니라 `실제로 전장에 남는 dps`로 바꾸는 장치다.

### 11-7. 조합 보정 업데이트

조합보너스/패널티도 v0.2에서는 아래 기준으로 다시 본다.

#### 추가 보너스

- `포위돌파보너스`: 근접 압박 해소 + 360도 커버 + 둔화/넉백이 함께 있을 때
- `역할균형보너스`: 단일처치/광역처치/생존유틸이 고르게 갖춰질 때

#### 추가 패널티

- `직선편중패널티`: 전방 화력만 높은데 측면/후방 대처가 없는 경우
- `접촉리스크패널티`: 높은 dps가 근접 유지에 과도하게 묶여 있는 경우
- `공백리스크패널티`: 강한 순간은 있지만 공격 공백이 긴 경우

### 11-8. v0.2 검증 기준

이제부터는 아래가 맞아야 식이 유효하다고 본다.

1. 직선딜 고화력 조합이 `처치력`은 높아도 `생존력`이 낮으면 총점이 과하게 치솟지 않아야 함
2. 장판/둔화/궤도형 조합이 `표시 dps`는 낮아도 `생존력` 덕분에 실제 체감과 비슷한 총점이 나와야 함
3. 태그 3단계 조기 완성이 포위 해소에 직접 기여하면 `태그시너지`가 실제보다 낮게 잡히지 않아야 함
4. `표준 조합 100` 기준에서 고점/저점 분포가 플레이 감각과 같은 순서로 나와야 함

### 11-9. v0.2 한 줄 판단

v0.2는 `높은 dps = 높은 전투력`이라는 단순식을 버리고,
`죽이는 힘`과 `포위를 버티는 힘`을 같은 비중으로 묶어서
웨일서바이버 실제 체감에 더 가깝게 맞추는 업데이트안이다.

## 12. v0.2 1차 샘플 비교

이번 비교는 `정밀 수치 확정`이 아니라,
v0.2가 실제 플레이 감각을 올바른 방향으로 정렬하는지 보는 용도다.

비교 대상은 아래 세 조합으로 둔다.

### 샘플 A — 표준형

- `blueSong + curseEcho + resonanceCursbeam`
- 성격: 공명/저주 중심, 태그 완성 빠름, 정면 화력과 중간 정도 범위 커버를 함께 가짐

읽힘:

- 단일처치력: 중상
- 광역처치력: 중
- 생존력: 중
- 태그시너지: 상
- 운영안정성: 중상

예상 판단:

- `표준 조합 100` 기준으로 두기 가장 무난함
- 처치력과 태그 폭발력은 좋지만, 포위 해소 전용 능력이 압도적이진 않음

### 샘플 B — 직선 고점형

- `narwhalLance + polarShock + pressureInscript`
- 성격: 관통/직선 화력 고점, 전방 돌파와 보스 압박에 강함

읽힘:

- 단일처치력: 상
- 광역처치력: 중상
- 생존력: 중하
- 태그시너지: 중
- 운영안정성: 중

v0.1에서 문제였던 점:

- 무기 dps가 높아서 총점이 과하게 튀었음
- 실제론 측후방 압박과 포위 유지에 약한데 그 약점이 잘 안 잡혔음

v0.2에서 기대하는 변화:

- `처치력`은 표준형보다 높게 유지
- 대신 `생존력`이 깎여서 총점이 표준형을 크게 압도하지는 않아야 함
- 즉 `강한 조합`이지 `무조건 최강`으로 튀면 안 됨

### 샘플 C — 장판 생존형

- `frostResonanceField + venomChargeField + toxinSwimmer`
- 성격: 장판 유지, 둔화/독 누적, 공간 통제 중심

읽힘:

- 단일처치력: 하
- 광역처치력: 중
- 생존력: 상
- 태그시너지: 중
- 운영안정성: 중상

v0.1에서 문제였던 점:

- baseDps가 낮아서 거의 저점 조합처럼 보였음
- 실제 플레이에서 포위 압박을 늦추고 빈 공간을 만드는 장점이 점수에 안 들어갔음

v0.2에서 기대하는 변화:

- `처치력`은 낮더라도 `생존력`이 크게 올라가야 함
- 총점이 표준형보다 조금 낮거나 비슷한 수준까지는 올라와야 체감에 가까움
- 즉 `느리지만 잘 안 죽는 조합`으로 해석되어야 함

### 샘플 D — 접촉 고위험형

- `bowheadIcebreaker + polarGuard + frostEcho`
- 성격: 높은 접촉/주변 화력, 냉기/공명 기반 근접 압박 해소

읽힘:

- 단일처치력: 상
- 광역처치력: 상
- 생존력: 중상
- 태그시너지: 중상
- 운영안정성: 중

v0.1에서 문제였던 점:

- `bowheadIcebreaker` baseDps가 너무 커서 총점이 비정상적으로 치솟았음

v0.2에서 기대하는 변화:

- 접촉 유지가 필요한 만큼 `실전가동률보정`이 들어가야 함
- 그래도 플레이어 주변 공간 확보력이 높으므로 생존력은 꽤 높게 잡혀야 함
- 결과적으로 `직선 고점형`보다 안정적일 수 있지만,
  숫자 하나만으로 모든 조합을 압살하는 수준까진 가면 안 됨

### 12-1. v0.2 기대 순서

현재 체감 기준으로 기대하는 정렬은 대략 이렇다.

1. `bowheadIcebreaker + polarGuard + frostEcho`
2. `blueSong + curseEcho + resonanceCursbeam`
3. `narwhalLance + polarShock + pressureInscript`
4. `frostResonanceField + venomChargeField + toxinSwimmer`

단,
3번과 4번은 게임 감각에 따라 뒤집힐 수도 있다.

왜냐면

- 3번은 `빨리 죽이지만 위기 대응이 약한 조합`
- 4번은 `천천히 죽이지만 위기 대응이 강한 조합`

이기 때문이다.

즉 v0.2가 맞게 작동하면,
이 둘은 `무기 dps 차이`만큼 벌어지지 않고 서로 비슷한 층에서 경쟁해야 한다.

### 12-2. 다음 검증 목표

다음 단계에선 아래를 실제 수치화하면 된다.

1. 각 무기에 `단일처치력 / 광역처치력 / 공간확보력 / 압박완화력 / 유지안정성` 5칸 점수 부여
2. 샘플 조합 4개에 합산 적용
3. 표준형 100 기준으로 상대 점수 산출
4. 실제 플레이 체감과 순서가 맞는지 비교

한 줄로 정리하면,
v0.2의 첫 검증 목표는 `직선 고점형이 과대평가되지 않고, 장판 생존형이 과소평가되지 않는지` 확인하는 거다.
