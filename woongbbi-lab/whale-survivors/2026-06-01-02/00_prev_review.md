# 이전 세션 검토

첫 세션 — 프로젝트 현황 파악에서 시작.

## 지금까지 읽은 상태

- 현재 브랜치는 `meta-unlock`
- 최근 커밋 흐름은 `비승인 무기/데이터 제거 -> 무기 v4 승인본 확정` 쪽으로 정리되어 있음
- 즉, 지금은 콘텐츠를 더 늘리기보다 `승인된 20종 무기`를 기준으로 런 구조와 성장 구조를 붙이는 타이밍에 가까움

## 이미 잡혀 있는 방향

- 메타 성장 메모는 `밖에서는 선택지 확장, 안에서는 빌드 완성`을 강하게 밀고 있음
- 런 페이싱 메모는 `초반 통제 -> 중반 성장 체감 -> 후반 해방감` 곡선을 원함
- 최근 대화에서는 `엑트 클리어 -> 성장 오픈 -> 다음 엑트 돌파` 한 줄 구조가 핵심으로 떠오름

## 아직 안 풀린 것

- 엑트 보상이 정확히 무엇을 여는지 아직 구조화되지 않음
- 그 보상이 왜 다음 엑트 공략에 실제 도움이 되는지 연결 규칙이 없음
- 영구 성장과 런 내부 성장의 경계가 흐려지면, 로그라이크 빌드 맛이 죽을 위험이 있음

## 이번 세션에서 이어받을 것

- `엑트 클리어 보상`을 수치 버프보다 `선택지/상호작용 해금`으로 설계해볼 것
- `다음 엑트에서 바로 체감되는 필요성`이 있는 보상만 후보로 남길 것
- 무기 v4와 태그 시스템을 기준으로, 지금 승인된 콘텐츠만으로도 돌아가는 구조를 우선 만들 것
