# 검증표 작성

이번 세션 아이디어를 아래 기준으로 평가하겠다.

| 기준 | 설명 | 가중치 |
|---|---|---:|
| 런 반복 동기 | 플레이어가 `다음 판을 바로 또 해보고 싶다`고 느끼는가 | 3 |
| 완주 동기 연결 | 현재 승리가 다음 엑트 또는 다음 런 목표와 자연스럽게 이어지는가 | 3 |
| 기존 시스템 적합성 | 승인 무기 20종, 태그 1~4단계, 항해 레이어만으로 성립하는가 | 3 |
| 수치 인플레 억제 | 영구 능력치 누적으로 런 내부 빌드 재미를 덮지 않는가 | 3 |
| 플레이어 이해도 | 해금 조건과 보상이 직관적으로 보이는가 | 2 |
| 확장성 | 4개 파일럿 태그로 시작해도 나중에 다른 태그에 붙이기 쉬운가 | 2 |
| UI/운영 부담 | 지금 프로젝트 단계에서 설명, 보상, 표시를 너무 많이 요구하지 않는가 | 1 |

## 채점 규칙

- 각 항목은 1점에서 5점으로 준다.
- 최종 점수는 `점수 x 가중치` 합산으로 계산한다.
- 내가 이번 세션에서 채택할 설계는 총점뿐 아니라, `기존 시스템 적합성`과 `수치 인플레 억제`에서 낮은 점수를 받으면 제외하겠다.
