# 아이디어 설계

이번 세션에서 내가 더 발전시키고 싶은 건 아래 2개다.

- 설계 A: `심해 허가서 드래프트`
- 설계 B: `4태그 연구 파일럿`

둘을 묶으면 `엑트 클리어로 연구 분야를 열고 -> 다음 런에서 실전 과제를 수행하고 -> 태그 3~4단계가 진짜 목표로 작동하는 구조`가 된다.

---

## 설계 A. 심해 허가서 드래프트

### 1. 시스템 흐름

1. 플레이어가 Act를 클리어한다.
2. `심해 허가서` 1장을 획득한다.
3. 보상 화면에서 3개 후보 중 1개를 고른다.
4. 후보는 서로 다른 축에서 1개씩 나온다.
5. 선택 결과는 즉시 스펙업이 아니라 `후보군 개방`, `가중치 상승`, `노드 등장`으로 반영된다.
6. 다음 런에서 플레이어는 `방금 내가 연 문`을 체감한다.

### 2. 보상 축

- `태그 연구권`
  - 특정 태그의 연구 과제를 활성화한다.
  - 예: `curse_research_permit`
- `무기군 편향`
  - 특정 태그/유형 무기 카드가 제안될 확률을 올린다.
  - 예: `wave_offer_bias`, `pressure_offer_bias`
- `항해 노드 허가`
  - 특수 해역이나 리스크-리턴 노드를 월드맵 후보군에 넣는다.
  - 예: `frost_trial_route`, `resonance_observatory`

### 3. 데이터 구조

```json
{
  "actRewardPools": [
    {
      "act": 1,
      "choices": [
        {
          "id": "permit_curse_research",
          "type": "tag_research_permit",
          "tag": "curse"
        },
        {
          "id": "bias_wave_weapons",
          "type": "offer_bias",
          "group": "wave",
          "weightDelta": 2
        },
        {
          "id": "unlock_pressure_route",
          "type": "route_unlock",
          "routeNode": "pressure_trial"
        }
      ]
    }
  ]
}
```

### 4. 오픈 곡선 규칙

- Act 1 보상은 `태그 3단계 진입권` 또는 `초기 방향성 강화` 위주로 둔다.
- Act 2 보상은 `태그 4단계 실전권` 또는 `특수 항해 노드`를 열게 한다.
- Act 3 보상은 `복수 태그 교차 운용`이나 `후반 해방감`을 강화하는 방향으로 둔다.

내가 여기서 중요하게 보는 건, 보상이 강함을 주는 게 아니라 `후보군 접근권`을 준다는 점이다.

## 설계 B. 4태그 연구 파일럿

이번 세션에서는 모든 태그를 다 건드리지 않고 아래 4개만 파일럿으로 본다.

- `curse`
- `resonance`
- `frost`
- `pressure`

이 4개는 최근 대화와 승인 무기 v4 문서에서 이미 중심축으로 자주 보였고, 공용/고유 무기 연결도 비교적 선명하다.

### 1. 시스템 흐름

1. 플레이어가 허가서 드래프트에서 특정 태그 연구권을 연다.
2. 다음 런부터 해당 태그의 연구 과제가 UI에 표시된다.
3. 플레이어는 런 안에서 태그 운용 과제를 달성한다.
4. 달성 시 태그 3단계 또는 4단계 관련 카드/이벤트/보상 후보군이 영구 개방된다.
5. 해금 후에도 빌드는 런 안에서 다시 맞춰야 하므로, 메타가 런을 덮지 않는다.

### 2. 데이터 구조

```json
{
  "tagResearch": [
    {
      "tag": "curse",
      "permitId": "permit_curse_research",
      "stages": [
        {
          "id": "curse_stage_1",
          "goal": "defeat_elites_with_curse_tier_3",
          "count": 8,
          "reward": "enable_curse_tier_3_sources"
        },
        {
          "id": "curse_stage_2",
          "goal": "clear_boss_with_curse_tier_4",
          "count": 3,
          "reward": "enable_curse_tier_4_sources"
        }
      ]
    }
  ]
}
```

### 3. 파일럿 표

| 태그 | 연구권이 열어주는 것 | 1차 과제 | 1차 보상 | 2차 과제 | 2차 보상 |
|---|---|---|---|---|---|
| `curse` | 저주 연구 UI, 저주 관련 보상 후보 등장 | 저주 3단계 상태로 엘리트 8기 처치 | 저주 3단계 소스 후보 개방 | 저주 4단계 상태로 보스 3회 처치 | 저주 4단계 소스 후보 개방 |
| `resonance` | 공명 연구 UI, 파형/공명 카드 후보 증가 | 공명 3단계 상태에서 500히트 누적 | 공명 파형 보상군 개방 | 공명 4단계 상태로 챔피언 처치 3회 | 공명 4단계 보상군 개방 |
| `frost` | 냉기 연구 UI, 냉기 시험 해역 등장 | 냉기 3단계 상태로 적 200기 빙결 | 냉기 제어형 카드 후보 개방 | 냉기 4단계 상태로 보스 처치 2회 | 냉기 종결형 후보 개방 |
| `pressure` | 압력 연구 UI, 압력 해역 등장 | 압력 3단계 상태로 장갑 적 50기 처치 | 압력 관통형 후보 개방 | 압력 4단계 상태로 엘리트 10기 처치 | 압력 폭발형 후보 개방 |

### 4. 승인 무기 20종 기준 연결 방식

- `curse`
  - `blueSong`, `narwhalLance`, `curseEcho` 중심
- `resonance`
  - `blueSong`, `bowheadIcebreaker`, `frostEcho`, `resonancePressure`
- `frost`
  - `bowheadIcebreaker`, `frostEcho`
- `pressure`
  - `narwhalLance`, `resonancePressure`

핵심은 `연구 보상 = 새 무기 생성`이 아니라 `이미 승인된 무기들과 더 깊게 만나게 만드는 문`이라는 점이다.

## 플레이어 경험

### 초반

- 처음부터 다 열려 있지 않아서 약간 부족한 느낌이 난다.
- 대신 `무엇을 먼저 연구할지`가 저장파일의 성격을 만든다.

### 중반

- Act 1 클리어 후 열린 허가서 하나만으로도 다음 런의 목적이 또렷해진다.
- `이번 판은 저주 연구 숙제`, `이번 판은 압력 해역 진입`처럼 플레이 이유가 분명해진다.

### 후반

- 여러 허가서와 연구 보상이 누적되면 태그 3~4단계 운용이 진짜 빌드 목표가 된다.
- 후반 해방감은 `숫자가 커졌다`보다 `내가 열어둔 시스템들이 맞물린다`는 쪽에서 나온다.

---

## 왜 지금 웨일서바이버에 특히 맞는가

- 최근 메모의 `밖에서는 선택지 확장, 안에서는 빌드 완성` 원칙과 직접 맞닿는다.
- 태그 1~4단계가 이미 중요한 언어라서, 메타 성장 축을 새로 만들지 않고 기존 축을 재사용할 수 있다.
- 승인 무기 20종 체제에서도 충분히 작동한다. 콘텐츠 대량 추가를 전제로 하지 않는다.

---

## 주의할 점

- 허가서가 즉시 수치 버프로 바뀌면 안 된다.
- 연구 과제는 `억지 숙제`처럼 보이면 안 되고, 태그 운용을 자연스럽게 유도해야 한다.
- Act별 보상은 특정 선택이 없으면 진행 불가가 아니라, `있으면 다음 판 계획이 더 선명해지는 정도`로 맞추는 게 좋다.
