# 신규 아이디어 브레인덤프

## 아이디어 1. 엑트 끝에서 받는 `심해 허가서`

- Act를 클리어하면 보상 화면에서 `태그 연구권`, `항해 노드 허가`, `무기군 편향` 중 하나를 고른다.
- 이 보상은 능력치가 아니라 다음 런의 후보군과 규칙을 바꾼다.
- 플레이어 입장에서는 `이번 승리로 다음 판의 방향을 내가 정했다`는 감각이 생긴다.
- 영감 출처: 리서치

## 아이디어 2. 태그별 `연구 과제 트랙`

- `저주`, `공명`, `냉기`, `압력`부터 4개 태그만 먼저 파일럿으로 잡고, 각 태그에 2단계 연구 과제를 둔다.
- 연구권을 연 뒤 실제 런 안에서 과제를 달성해야 태그 3~4단계 관련 후보가 열린다.
- 태그 설명문이 추상 텍스트가 아니라, 플레이어가 직접 개척한 시스템처럼 느껴질 수 있다.
- 영감 출처: 이전세션

## 아이디어 3. 항해 맵에 `연구 해역` 노드 추가

- 일반 전투 노드가 아니라 `이번 런에서 특정 태그 과제를 노리기 좋은 해역`을 넣는다.
- 예를 들면 `압력 해역`은 좁은 동선과 장갑 적, `냉기 해역`은 군집 적 위주로 태그 숙제를 밀기 좋게 만든다.
- 이렇게 하면 항해 레이어가 단순 보상 분기 이상으로, 메타 목표 수행 공간이 된다.
- 영감 출처: 직접생각

## 아이디어 4. 무기 카드에 `연구 대상` 배지 표시

- 지금 열린 연구 과제와 직접 연결되는 무기 카드에는 작은 배지를 붙인다.
- 예를 들어 `curseEcho`가 저주 연구와 맞물리면, 카드 픽 순간에 `이번 판 목표와 연결됨`을 바로 보여준다.
- 태그 시스템이 복잡해질수록 이런 시각적 연결장치가 필요해 보인다.
- 영감 출처: 리서치

## 아이디어 5. 엑트별 `조금 부족한 상태`를 의도적으로 남기는 오픈 곡선

- Act 1 직후에는 태그 3단계 진입권만 보여주고, Act 2를 지나야 태그 4단계 실전권을 연다.
- 후반 해방감을 위해 초반에 일부러 덜 열린 상태를 유지하는 방식이다.
- 최근 메모의 `초반 통제 -> 중반 성장 체감 -> 후반 해방감`을 가장 직접적으로 구현하는 아이디어다.
- 영감 출처: 이전세션
