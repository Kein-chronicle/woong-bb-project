# 이전 세션 검토

## 내가 이전 세션들에서 배운 것

- 웨일서바이버의 메타 성장은 `영구 수치 상승`보다 `선택지 확장`에 더 잘 맞는다.
- `엑트 클리어 -> 다음 런에서 새 문이 열림` 구조가 런 반복 동기와 완주 동기를 같이 잡아준다.
- 태그 시스템은 전투 안 규칙으로만 두기보다, 메타에서 `연구`, `면허`, `목표`의 언어로 재활용할 가치가 크다.

## 아직 안 풀린 것

- Act 1, 2, 3에서 정확히 어떤 종류의 보상을 얼마나 풀지 표준안이 아직 없다.
- `저주`, `공명`, `냉기`, `압력` 같은 핵심 태그를 어떤 과제로 열고 어떤 보상으로 이어줄지 파일럿 표가 없다.
- 항해 노드 해금과 태그 연구가 서로 어떻게 연결되는지, 플레이어 표면 경험 기준으로 아직 덜 정리됐다.

## 이번 세션에서 이어받을 것

- 나는 이번에 `엑트 보상 드래프트`와 `태그 연구 과제`를 따로 보지 않고, 하나의 오픈 곡선으로 묶어서 보겠다.
- 특히 `승인 무기 20종만으로도 충분히 굴러가는가`를 계속 기준으로 잡겠다.
- 결과물은 `어떤 문을 언제 여는지`, `왜 다음 런을 또 하게 되는지`, `태그 3~4단계가 어떻게 실제 목표가 되는지`를 더 선명하게 만드는 쪽으로 정리하겠다.
